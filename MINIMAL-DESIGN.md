# Wellbeing Minimal Navy

Wellbeing uses a quiet, information-first interface derived from the supplied homepage reference.

## Foundation

- Dark background: `#191919`
- Primary text: `#FFFFFF`
- Action and selected-control fill: `#D9D9D9`
- Muted text and dividers: white at reduced opacity
- Light mode reverses the contrast while keeping the same geometry and hierarchy.

## Typography

- Google Font Inter with a system sans-serif fallback throughout.
- The WELLBEING wordmark and section headings use bold uppercase text.
- Eyebrows, metadata and controls use deliberate tracking.
- Workout names and key values stay in readable mixed case.

## Geometry and grouping

- Square or nearly square utility controls.
- Flat rectangular primary actions.
- No glass blur, ambient glow, gradient surface, decorative halo or floating card shadow.
- Sections are grouped with whitespace and one-pixel dividers rather than containers.
- Pills are reserved only where a circular form communicates real data, such as a timer or score.

## Responsive behavior

- Wide layouts retain generous horizontal breathing room.
- Mobile layouts reduce padding while preserving 44px minimum action targets.
- Metric groups wrap into two columns or a single column before text becomes cramped.
- Long routine and exercise names always wrap.
